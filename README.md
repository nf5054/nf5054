## How I Use Them

**Systems & Hardware** C++20 with CUDA and TensorRT for hardware acceleration and computer vision. Rust for fast system tools and Discord bots. WebAssembly for running native game physics in the browser.

**Frontend** React and Next.js for web apps with TypeScript and Tailwind CSS to design quickly. Three.js for interactive 3D and liquid glass visuals. Vue, Nuxt, and Angular when specific projects call for them.

**Backend** Node.js and FastAPI for web services and APIs. Go for high-throughput services. Django, .NET, and Spring Boot for larger systems.

**Game Systems** Luau with Rojo for Roblox gameplay systems, movement physics, wall-running mechanics, and server-authoritative netcode.

**Databases** PostgreSQL for relational data, SQLite for self-contained desktop apps, Redis for caching, and MongoDB when data shapes change often.

**DevOps & Infrastructure** Git and GitHub for version control, Docker for service isolation, Postman for testing APIs, and Nginx in front of servers on Linux and Ubuntu.
